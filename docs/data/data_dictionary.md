# Column Data Dictionary

## Scope and ownership boundary

This dictionary covers every committed CSV source column and the curated Gold reporting interfaces consumed by Power BI. SQL DDL and TMDL remain authoritative for executable types and nullability. All records are synthetic. `Owner` names a repository role only; named business/data owners are not assigned and must be established for a real deployment.

## Source fixtures

CSV has no physical nullability or native data type. `Nullable` therefore states the ingestion contract: `Rejected if blank` means a missing value cannot be published; `Accepted/derived` means the transformation handles blanks explicitly.
